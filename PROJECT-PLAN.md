## Definition of Done

- The business problem and technical scope are clear.
- Architecture and design decisions are documented.
- Configuration or implementation steps are reproducible.
- Security and operational risks are addressed.
- Test cases include expected and actual outcomes.
- Evidence is sanitized and organized.
- Business value and lessons learned are stated plainly.
- The main README links to all completed artifacts.

## Working Rules

1. Never publish credentials, tenant identifiers, personal data, PHI, secrets, or proprietary information.
2. Use fictional names and reserved/example addresses where possible.
3. Explain why a control exists, not only where it was clicked.
4. Capture failures and troubleshooting; they are part of the evidence.
5. Do not mark an item complete until its artifact or evidence is committed.
